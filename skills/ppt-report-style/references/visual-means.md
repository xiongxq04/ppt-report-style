# 视觉手段与纯文字页

> 阈值唯一权威是 `references/profiles.json` 与 SKILL.md；本文件只做展开说明。

## 每页至少一种视觉手段

原表述"每页一个视觉承载物"已废弃：它会把每一页都逼成示意图页。现在的要求是**每页至少有一种视觉手段**，手段可以轻，但不能没有。

| 类别 | 手段 | 自动可查 |
| --- | --- | --- |
| 信息结构 | 流程、关系图、时间线、层级图 | 是（骨架与关系模型） |
| 数据表达 | 图表、数据标注、比例条 | 是（图表对象） |
| 媒体表达 | 实景图片、示意图、地图 | 是（图片对象） |
| 排版表达 | 引语、侧栏、标题与正文的空间对比；大数字 callout **仅 fast/balanced 档可用**（balanced 限数据页 ≤36pt；strict 全面禁止，关键数字句内黑体强调） | 部分（多级字号；大数字由 `TYP.POSTER` 机审） |
| 空间表达 | 非对称布局、留白、重心偏移、明确阅读路径 | 否，需人工审阅 |

两级判定：

- **可自动检查**：页面是否存在明确的骨架类型、图表、图片、表格、图形结构或字号层级。
- **需要审阅**：这些手段是否真的改善了信息理解。

脚本不会因为页面"有一个大标题"就认定视觉设计合格。`LAY.MEANS` 只在纯文字页（无图/表/图表/图形结构）且**全页只有一档字号**（主次拉不开）时报 SUGGESTION——封面/章节页（≥36pt 标题）豁免；有层级的多档纯文字页不报。

## 纯文字页

允许存在纯文字页，但必须满足：

- 明确的**字号层级**：至少两级，主句与说明拉开差距。
- 有意图的**留白**：不把文字铺满版面。
- 清楚的**对齐结构**：左对齐或居中成组，不是一大段文字居中堆着。
- 占比按档位：封面/章节页（≥36pt 标题）不计入统计；内容页纯文字占比 balanced >30% 报警（`LAY.PURETEXT`），strict 阈值放宽到 60%（学术 deck 允许更多纯排版页），fast 不检查。

适合纯文字页的页面：核心观点页、引用页、章节转折页、结尾页。

不适合：本该用数据说话的页面、本该展示流程或关系的页面、需要并列比较的页面。

## 反模式

- 给每一页都强行配示意图，结果图与内容无关。
- 用图标代替关系：一排图标不能表达因果和先后。
- 纯文字页只有一种字号，靠加粗当作层级。
- 用装饰性色块填满留白，把呼吸感挤掉。
- 为了"每页不一样"随机换形状。
