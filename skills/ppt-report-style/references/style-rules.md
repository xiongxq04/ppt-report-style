# 个人视觉规范：档位与形状规则

> 阈值唯一权威是 `references/profiles.json` 与 SKILL.md；本文件只引用、不重复阈值。
> 配色预设见 `references/palette-system.md`，布局约束见 `references/layout-patterns.md`，
> 视觉手段见 `references/visual-means.md`，效果与母题见 `references/effect-budget.md`，配图见 `references/image-sourcing.md`。

## 档位（三档，真源在 profiles.json）

| 维度 | `fast`（L1） | `balanced`（L2，默认） | `strict`（L3） |
| --- | --- | --- | --- |
| 场景 | 内部草稿、随手分享 | 常规组会、项目汇报 | 答辩、投稿配套、正式评审 |
| 正文下限 | 14pt | 16pt | 16pt（HF 页眉页脚档 14pt） |
| 字阶 | 不强制 | 6 档机审 | 6 档机审（HF 14pt 除外） |
| 文字色 | 预设内不限量 | 预设 token，色相 ≤3 组 | 预设 token，点缀每页 ≤2 形状 |
| 大数字 callout | 允许 ≤44pt | 仅数据页 ≤36pt | 禁止（句内黑体强调） |
| 结论行前缀 | 允许 | 禁止 | 禁止（机审 0 次） |
| 装饰预算 | 图标、章节母题允许 | 淡卡片+编号，无图标 | 仅发丝线/字重/发丝边框卡片 |
| 骨架重复 | 不检查 | 连续 3 页同骨架 WARNING | ≥10 页才 SUGGESTION |
| 备注下限 | 0 | 90 字/页 | 150 字/页 |

- **模板跟随模式**允许继承原模板的颜色、字体和版式；不要为了本规范强行改造已有品牌模板；
  但对比度 ≥4.5:1（P0）与"不覆盖源文件"两条任何档位不豁免。
- 继承色无法判定对比度的，报警告而不是放行（`PAL.INHERIT`）。

## 默认页面骨架

骨架尺寸应相对页面宽度计算，不写死为某一种非标准幻灯片尺寸。

- 左右边距约为页宽的 4%。
- 标题区约占页面高度的 20%。
- 常规内容页可采用左 55%、右 45% 的双栏结构，也可用全宽单栏、上下分区、网格/矩阵、主图+侧栏或中心辐射（见 `references/layout-patterns.md`）。
- 页眉小字和页码保持同一批页面一致。
- 标题、正文和内容承载区形成清晰层级；结论条只在有独立结论价值时出现。

## 主视觉形状

主视觉形状应表达内容关系，不为了“每页不同”而随机更换。文字承载区优先保持简洁、对齐和可读。

| 形状 | 适合表达 | 示例 |
| --- | --- | --- |
| 圆形 | 循环、聚合、中心关系、比例 | 周期流程、核心概念、占比 |
| 平行四边形 | 变换、映射、输入到输出、向量空间 | 线性变换、处理过程、状态迁移 |
| 圆柱 | 层次、容量、累积、存储 | 数据分层、资源池、逐层压缩 |
| 三角形 | 方向、优先级、层级 | 上升趋势、三层结构 |
| 六边形 | 模块、网络、并列单元 | 系统组件、多维关系 |

使用原则：

- 一页通常只建立一种主形状语言，文字块和数据表可继续使用矩形。
- 圆、平行四边形、圆柱等应与页面语义一致，不做纯装饰。
- 不要求每页更换形状；同一系列页面可以共享同一种形状语言。
- 避免在一页同时堆叠圆、三角、圆柱和多边形形成“形状动物园”。
- 形状中的文字必须留足安全区，不能贴边或被弧线裁切。
- 同一页所有形状坐标按 0.05in 网格对齐，视觉才成体系。

## 页面类型

| 页面 | 推荐结构 | 是否必须图表 |
| --- | --- | --- |
| 封面 | 标题、副标题、作者/日期、必要标识 | 否 |
| 目录 | 章节与页码或主题概览 | 否 |
| 章节页 | 章节编号、命题式标题、简短引导 | 否 |
| 论点页 | 导语、证据、判断、结论 | 否 |
| 数据页 | 表格、图表、数字卡或组合证据 | 是，仅在数据需要时 |
| 机制/流程页 | 流程、因果、时间线或方块 | 否 |
| 对比页 | 表格、双栏、矩阵或差异图 | 视内容而定 |
| 附录页 | 口径、来源、详细数据、备答 | 否 |

## 文字与数据

- 标题直接写主题或判断，避免口水话和演示指令。
- 指标名、数值、单位和口径保持清楚；同一层级避免“上面标签、下面数字”的重复结构。
- 数据只使用用户材料或可追溯实算。
- 材料中的旧数据不静默改成新数据；需要更新时标明新来源和口径。
- 来源和口径默认进备注，用户要求留痕或材料需要公开核验时在片上保留简短出处。

## 图表

- 只有数据关系需要时才使用图表，不用图表填满版面。
- 多系列图优先保证系列可区分，再考虑配色额度。
- 负值、零基线、截断轴和百分比必须真实表达。
- 数值标签不得贴边或被裁；类别多时保留间距。
- 散点图使用点标记，不默认连线。
- 图片按框等比裁切，不拉伸变形。

## 结论条：按内容决定

### 适合使用

- 页面证据较多，必须把分散信息收束成一句判断。
- 需要明确说明结论强度、适用边界、风险或行动建议。
- 标题表达主题，但页面落点需要单独强调。
- 表格、多图或对比结构完成后，需要指出关键差异。

### 不应使用

- 封面、目录、章节页和附录页。
- 标题已经清楚表达判断，再加结论只会重复。
- 纯展示页、图片页、流程步骤页或没有明确落点的页面。
- 仅为保持页面骨架一致而添加。
- 结论只是复述正文或重复标题。

结论条应使用本页真实内容形成一句收束，不得使用模板化空话。位置也不必固定在底部，可放在相关证据块之后或页面主判断区域。

## 讲稿

- 先按整场汇报时长分配每页讲稿，再写逐字稿。
- 核心内容页通常可按 45～90 秒规划，约 1 分钟逐字稿是常见落点。
- 封面、目录、章节页和附录页按实际讲解需要写备注。
- 口径、来源、备答写入备注，但不要求每页机械达到固定字数；默认门槛 150 字/页可用 `--notes-min` 调整。
