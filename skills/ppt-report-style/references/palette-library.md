# 外部色板库（palette-library）

> 本文件收录 7 组外部配色方案的**实算数据**，是新预设与自定义序列色的选材来源，不是可用色清单。
> 全部对比度与 HSL 由 `scripts/palette_utils.py`（`contrast_ratio` / `hsl`）对白底实算，与本文一致；
> 文档与本文件冲突时，以脚本实算为准。判据见下，不改写任何硬门槛（硬门槛见 palette-system.md）。

## 总述：怎么读、怎么用

**三条使用路径**（按优先级）：

1. **直接用预设**：A/B/C/D 已是完整 token 角色表，`--preset` 整套换。不要从本文件零散取色当文字色。
2. **挑序列色**：从本文件挑对比度 1.6~3.4:1 的中明度色作图表 series（图形填充不限对比度），文字仍用当前预设 token。
3. **派生新预设**：走文末"晋升规则"，四步走完才允许写进 profiles.json。

**判定线**（与 `palette_utils.py` 常量一致）：

| 对白底对比度 | 判定 | 能干什么 |
| --- | --- | --- |
| ≥ 4.5:1 | 文字档 | 正文、标题、点缀（占点缀限额） |
| ≥ 3.0:1 | 图形档 | 大字（≥18pt 常规 / ≥14pt 加粗）、图形边界、描边 |
| < 3.0:1 | 填充档 | 图表柱、色块、底色、分区；禁止承载正文小字 |

**方法论**：本库全部数据一次实算生成，公式与机审同源（WCAG 相对亮度）。任何人复核只需重跑：

```text
python scripts/palette_utils.py --contrast 26465E FFFFFF
```

**近亲警告**：`26465E`（预设 D）、`26445E`（十四宫格）、`283E4E`（预设 B）三者色相 205~210°、明度 0.23~0.26，对白底 9.9~11.2:1——**是同一个"深蓝墨"的近亲，不要当成三种不同主色同时用**。选主色时三者取一即可。

**7 组概览**：

| 组 | 结构类型 | 文字档数量 | 最佳用途 |
| --- | --- | --- | --- |
| 1 基础三色 | 一主一辅一底 | 1 | 近亲为预设 A，仅作备选 |
| 2 高饱和六色 | 多色相并列 | 2（深红/深绿） | 多系列对比柱图（色盲不友好，慎用） |
| 3 清新浅色三色 | 全浅档 | 0 | 背景、分区、淡卡片 |
| 4 柔和九色 | 马卡龙全浅档 | 0 | 淡卡片底色（balanced 档装饰预算内） |
| 5 SCI 经典 16 色 | 多系列图例色板 | 1（紫） | 科研图例；单页 ≤3 组色相，按需挑 3 色 |
| 6 五色循环 | 深锚点+暖色渐变 | 1（深蓝） | **已晋升为预设 D** |
| 7 四组分角色小色板 | 配对/渐变/散点 | 组C 2 个 | 组B 双系列渐变、组C 深浅配对语义色 |
| 附 十四宫格 | 明度×色相双阶梯 | 9 | 近亲为预设 B；浅色档作底色 |

## 晋升规则：从本库到新预设

1. **选锚点**：从目标组挑深档色作 accent，对白底必须 ≥4.5:1（`--contrast` 核对）；锚点不得与现有预设近亲（见"近亲警告"）。
2. **派生脚手架**：`python scripts/palette_utils.py --scale <锚点>` 生成七档色阶，取深侧 1~2 档为 accent_deep（预设 D 取第 2 档 `1D3648`）、次浅档为 chart_neutral、最浅档为 hair，逐档 `--contrast` 复核。
3. **选序列色**：series 从同组中明度色里取（参考 1.6~3.4:1 区间），不跨组混搭。
4. **入册**：写入 profiles.json 的 `presets`，跑 `palette_utils.py --check --preset <新>`（文字 token 自动断言 ≥4.5:1）与 `run_regression.py`（新预设自动纳入冒烟），同步 SKILL.md 预设表后提交。
