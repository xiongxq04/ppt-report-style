# 模板跟随改版流程

模板跟随改版用于沿用已有 PPT 的视觉体系。完整过程分为四步，每一步都有独立产出。

## 1. 提取素材和配色

从源 PPT 中提取：

- 主题色、辅助色、强调色和背景色；
- 字体、字号层级、行距和段落间距；
- Logo、图片、图标、纹理和装饰元素；
- 母版、版式、页眉页脚、页码和日期规则；
- 图表样式、表格样式、描边、阴影和圆角；
- 动画、切换、媒体和嵌入对象。

把提取结果整理成四类：中性色、主题色系列、对比色、辅助色。原配色只有单一时，用 `palette_utils.generate_scale()` 派生同色相深浅档，再判断各档用途。

产出：《素材清单》和《视觉规范摘要》。

注意事项：

- 不覆盖或重写源 PPT。
- 不因为无法编辑而删除复杂对象。
- 不提取、不复制、不重建 SmartArt；需要重设计对应内容时改用普通形状、文本或表格。
- 品牌模板的字体和颜色优先于本 skill 的默认配色（P1 高于 P2）。
- 继承色必须满足对比度门槛（P0）；原模板存在浅底浅字时先提示，再决定是否调整。

## 2. 分析 PPT

逐页记录：

- 页面类型：封面、目录、章节页、内容页、数据页、附录等；
- 原版式规律和不同页面的差异；
- 标题层级、边距、栏宽、对齐、留白和内容密度；
- 关系模型与页面骨架，可用 `--layout-report` 辅助分类；
- 文字溢出、元素重叠、图表不可读等实际问题；
- 必须保留的母版、素材、动画和特殊结构。

产出：《逐页分析表》和《待调整页面清单》。

## 3. 选取页面重新设计

按以下优先级选页：

1. 明显溢出、重叠或不可读的页面；
2. 与整套风格不一致的页面；
3. 信息结构混乱、标题无法表达结论的页面；
4. 数据关系表达不准确的页面；
5. 仅需微调的页面。

重设计时：

- 只修改选定页面，其他页面保持不变；
- 复用提取出的字体、颜色、素材和几何语言；
- 按内容关系换骨架，允许与原模板骨架不同，但要保持同一视觉语言；
- 不为了个人默认骨架破坏原有模板；
- 输出新文件，附一页变更说明。

产出：重设计页面、变更说明和新版 PPT。

## 4. 风格复核

逐页比较新旧版本：

- 配色、字体和字号层级是否一致；
- 页眉、页码、标题位置和边距是否一致；
- 图片裁切、图标、图表和表格样式是否一致；
- 阴影、圆角、描边和装饰密度是否一致；
- 页面之间是否保持同一视觉语言；
- 动画、切换、母版、媒体和嵌入对象是否被意外改变；
- 新配色是否仍在原模板的色相体系内，对比度是否达标。

产出：《风格复核表》。

发现偏差时回到第 3 步只调整相关页面，不重新生成整套 PPT。属于刻意保留的差异，用 `[例外:…]` 写明理由。
