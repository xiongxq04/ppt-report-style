# 布局与关系模型

布局规则权威定义在本文件。核心原则：**先判断内容关系，再选骨架**，而不是把内容塞进同一个模板。

## 三字段元数据

每页在大纲里记录三个字段，检查脚本按这三个字段统计：

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| 关系模型 | 内容之间的逻辑关系 | 对比、流程、层级、循环、时间线 |
| 页面骨架 | 版面分区方式 | 左右双栏、上下分区、主图+侧栏、中心辐射 |
| 视觉手段 | 承担视觉任务的手段 | 图片、图表、表格、图形结构、大数字、多级字号 |

`python scripts/check_ppt.py deck.pptx --layout-report` 会输出每页的分类，可直接抄进大纲核对。

## 关系模型库

| 关系 | 适合表达 | 推荐手段 | 反例 |
| --- | --- | --- | --- |
| 并列 | 同级要点、平行模块 | 等宽卡片、等宽条带 | 把并列内容写成先后顺序 |
| 对比 | 两组方案、前后变化 | 左右双栏、对照表、镜像结构 | 用箭头硬造因果 |
| 流程 | 步骤、操作顺序 | 箭头形、编号节点 | 用一排方块暗示顺序 |
| 因果 | 原因到结果 | 链路图、递进箭头 | 只说现象不给机制 |
| 层级 | 总目标到具体实证 | 逐层加宽的条带、三角 | 用字号大小暗示层级 |
| 循环 | 闭环、迭代、聚合 | 中心圆加周边节点 | 先后关系画成闭环 |
| 辐射 | 一个中心多方向展开 | 中心节点加卫星节点 | 中心是装饰性图标 |
| 矩阵 | 多维对照、口径对照 | 表格 | 用方块拼出表格效果 |
| 递进 | 程度递进、阶段升级 | 阶梯、渐进条 | 三级内容做成等大 |
| 演变 | 形态或状态演化 | 变形序列、平行四边形容器 | 时间与阶段混在一起 |
| 空间 | 地理、区位、布局 | 地图、区位示意 | 拿风景照当位置说明 |
| 时间线 | 时间顺序、里程碑 | 主轴加节点 | 把日常进度全排上 |

## 页面骨架库

| 骨架 | 结构 | 适合 |
| --- | --- | --- |
| 全宽单栏 | 单列，上下分层 | 表格、密集数据、纯文字观点页 |
| 左右双栏 | 左右两个内容块，中间留缝 | 对比、图文并置 |
| 上下分区 | 三段横向分区 | 导语—主体—结语的推进 |
| 网格/矩阵 | 等宽卡片两行以上 | 并列要点、模块清单 |
| 主图+侧栏 | 一侧图片或图表，一侧文字 | 实景与数据为主 |
| 中心辐射 | 中心节点加周边节点 | 循环、聚合、辐射 |

## 约束与检查

- **连续 3 页不得使用同一主骨架。** 例外：属于"逐步揭示同一张图"等有明确目的的连续序列，在该页备注写 `[例外:骨架重复]` 并说明理由。
- 方块、矩阵类页面（骨架为网格/矩阵，或关系为矩阵对照、并列）占比 **≤ 35%**，整套不少于 6 页时才统计。
- 全套演示至少覆盖 **4 种关系模型**（不足 6 页不强制）。
- 关系模型的判定由脚本做保守估算，最终以人工审阅为准；脚本报错不代表内容关系错，只代表该页没有可识别的结构。

## 形状与几何

主视觉形状按语义选择，形状表与使用原则见 `references/style-rules.md`：圆形用于循环与聚合，平行四边形用于变换与映射，圆柱用于层次与容量，三角形用于方向与优先级，六边形用于模块与网络。一页只建立一种主形状语言，避免"形状动物园"。

元素关系要有变化：允许斜向、层叠、环绕、路径连接，不必全部水平垂直摆放；但坐标仍按 0.05in 网格对齐，保证成体系。
