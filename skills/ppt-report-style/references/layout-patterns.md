# 布局与关系模型

> 阈值唯一权威是 `references/profiles.json` 与 SKILL.md；本文件只做展开说明。
> 核心原则：**先判断内容关系，再选骨架**，而不是把内容塞进同一个模板。

## 三字段元数据

每页在大纲里记录三个字段，检查脚本按这三个字段统计：

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| 关系模型 | 内容之间的逻辑关系 | 对比、流程、层级、循环、时间线 |
| 页面骨架 | 版面分区方式 | 左右双栏、上下分区、主图+侧栏、中心辐射 |
| 视觉手段 | 承担视觉任务的手段 | 图片、图表、表格、图形结构、大数字、多级字号 |

`python scripts/check_ppt.py deck.pptx --layout-report` 会输出每页的分类，可直接抄进大纲核对。

## 关系模型库

| 关系 | 适合表达 | 推荐手段 | 反例 |
| --- | --- | --- | --- |
| 并列 | 同级要点、平行模块 | 等宽卡片、等宽条带 | 把并列内容写成先后顺序 |
| 对比 | 两组方案、前后变化 | 左右双栏、对照表、镜像结构 | 用箭头硬造因果 |
| 流程 | 步骤、操作顺序 | 箭头形、编号节点 | 用一排方块暗示顺序 |
| 因果 | 原因到结果 | 链路图、递进箭头 | 只说现象不给机制 |
| 层级 | 总目标到具体实证 | 逐层加宽的条带、三角 | 用字号大小暗示层级 |
| 循环 | 闭环、迭代、聚合 | 中心圆加周边节点 | 先后关系画成闭环 |
| 辐射 | 一个中心多方向展开 | 中心节点加卫星节点 | 中心是装饰性图标 |
| 矩阵 | 多维对照、口径对照 | 表格 | 用方块拼出表格效果 |
| 递进 | 程度递进、阶段升级 | 阶梯、渐进条 | 三级内容做成等大 |
| 演变 | 形态或状态演化 | 变形序列、平行四边形容器 | 时间与阶段混在一起 |
| 空间 | 地理、区位、布局 | 地图、区位示意 | 拿风景照当位置说明 |
| 时间线 | 时间顺序、里程碑 | 主轴加节点 | 把日常进度全排上 |

## 页面骨架库

| 骨架 | 结构 | 适合 |
| --- | --- | --- |
| 全宽单栏 | 单列，上下分层 | 表格、密集数据、纯文字观点页 |
| 左右双栏 | 左右两个内容块，中间留缝 | 对比、图文并置 |
| 上下分区 | 三段横向分区 | 导语—主体—结语的推进 |
| 网格/矩阵 | 等宽卡片两行以上 | 并列要点、模块清单 |
| 主图+侧栏 | 一侧图片或图表，一侧文字 | 实景与数据为主 |
| 中心辐射 | 中心节点加周边节点 | 循环、聚合、辐射 |

## 海报版式的可迁移经验

> 来源：埃米编辑《从新手到高手！学术海报制作全攻略》（知乎，2024-11-14）及其 9 张版式实例与线框图。海报是"单页大幅面 + 一米外扫读"的媒介，与汇报 PPT 的差异在观看距离、信息密度（全文 ≤500 词、5 分钟读完）与阅读顺序的控制方式；剔除媒介差异后，版式方法论可直接迁移。本节只收可迁移项，海报专有内容（规格尺寸、横竖版、分辨率等会议要求）不进本规范；不新增机审规则与阈值，验收走人工项。

### 方法论四条

1. **字号下限是观看距离的函数**：海报按一米外可读定字号，所以正文极大；汇报 PPT 按投影距离定，对应本规范正文 ≥16pt 的档位下限。两个媒介推出同一结论——"缩小字号塞内容"永远错，装不下就减字。
2. **单页只设一个视觉主角**：海报线框图的原话是"graphical abstract, the bigger the better"；9 张获奖实例每张只有一个 hero（中央大图、大图示摘要或一句核心结论）。对应本规范：主图+侧栏骨架里图要真正承担主角、不做插图装饰；纯文字页的主角是判断行本身。
3. **阅读顺序要显式引导，不能默认读者自己找**：海报三板斧 = 放大并区分各级标题、板块边界清晰、箭头和编号引导。PPT 有讲者控场可弱化编号，但网格/矩阵等多板块并列页仍建议编号，或方位顺序固定（先左后右、先上后下）并全篇一致。
4. **先做内容减法，再做版式**：海报把方法并进结果、讨论并进结论，引用与致谢刻意缩小退后。对应本规范：一页装不下先合并段落或砍实证条，不缩字号缩行距；辅助信息（口径、来源、致谢类内容）退到备注与次级灰图注，不与正文争权重。

### 海报骨架 → 本规范骨架对照

| 海报骨架 | 海报做法 | 迁移到 PPT 单页 |
| --- | --- | --- |
| 经典三栏 | 横版 Intro/Methods/Results 三列纵读 | 网格/矩阵骨架的三卡片并列：栏宽相等、顶线对齐 |
| banner 标题条 + 编号 | 全宽色条标题 + 编号串起阅读顺序 | 标题条精神对应命题式页面标题；strict 档不用色条，用发丝线 + 黑体标题；编号仅多板块页用 |
| 中心主图辐射 | 6 个板块环绕中央 hero 图 | 即上方"中心辐射"骨架，hero 图就是中心节点 |
| 侧栏轨 + 大图 | 左缘竖排小节标题轨，主图占半页 | "主图+侧栏"骨架的镜像变体：侧栏放导航/口径，主图放大到视觉主导（经验上 ≥ 半页） |
| 三分法偏置 | 标题右偏 2/3、主图偏左 1/3 的不对称构图 | 仅 fast/balanced 档可用作封面、章节页构图；strict 档维持对齐统一，不追偏置 |
| #betterposter | 窄栏摘要轨 + 中央一句核心结论 + 二维码 | 精神已被"命题式标题 + 判断行"覆盖：先给结论再给支撑；不照搬大字（`TYP.POSTER` 会拦） |

### 验收清单（人工项）

- 这页有且只有一个视觉主角（图或判断行）吗？出现两个 = 版式没有重点。
- 多板块并列页的阅读顺序，不讲也能按编号或方位走通吗？顺序全篇一致吗？
- 辅助信息（口径、来源、致谢类内容）退到次级灰、图注或备注了吗？和正文拉开权重了吗？
- 内容装不下时做的是减法（合并、砍条目）而不是缩字号缩行距吗？
- 若用了偏置构图，当前档位允许吗（strict 不可）？

## 约束与检查

- **连续 3 页不得使用同一主骨架（按档位分治）**：balanced 报 WARNING；strict 仅在 deck ≥10 页时降为 SUGGESTION（统一骨架是学术美德，短 deck 不检查）；fast 不检查。例外：属于"逐步揭示同一张图"等有明确目的的连续序列，在该页备注写 `[例外:骨架重复]` 并说明理由。
- 方块、矩阵类页面（骨架为网格/矩阵，或关系为矩阵对照、并列）占比 **≤ 35%**，整套不少于 6 页时才统计。
- 全套演示至少覆盖 **4 种关系模型**（不足 6 页不强制）。
- 关系模型的判定由脚本做保守估算，最终以人工审阅为准；脚本报错不代表内容关系错，只代表该页没有可识别的结构。

## 形状与几何

主视觉形状按语义选择，形状表与使用原则见 `references/style-rules.md`：圆形用于循环与聚合，平行四边形用于变换与映射，圆柱用于层次与容量，三角形用于方向与优先级，六边形用于模块与网络。一页只建立一种主形状语言，避免"形状动物园"。

元素关系要有变化：允许斜向、层叠、环绕、路径连接，不必全部水平垂直摆放；但坐标仍按 0.05in 网格对齐，保证成体系。
