# 配色系统（预设 A/B/C）

> 阈值唯一权威是 `references/profiles.json` 与 SKILL.md；本文件只做展开说明，不重定义任何色值与限额。
> 可执行实现：`scripts/palette_utils.py`（对比度/色相/派生）与 `scripts/verify_ppt_style.py`（PAL.* 规则）。

## 三套预设，每套是完整的 token 角色表

| Token | 作用 | 文字可用？ |
| --- | --- | --- |
| `ink` 墨 | 正文、标题 | 是（21:1） |
| `muted` 次级灰 | 图注、口径、副标、落款 | 是（5.1:1） |
| `hair` 发丝线 | 页眉页脚线、分隔线；**页眉页脚文字专用档**（仅页眉区/页脚区位置享受 14pt+对比度豁免） | 仅 HF 区 |
| `chart_neutral` 图表灰 | 未点亮的柱/系列 | 否（只做图形） |
| `accent` 点缀 | 图表重点、表格关键行、当前章、正文关键数字 | 是（≥5.2:1） |
| `accent_deep` 点缀深 | 小字号强调（若需要） | 是 |
| `series` 序列色 | 多系列图表的第二、三色（色盲安全组合） | 否（图表专用） |

| 预设 | 定位 | accent | 出处 |
| --- | --- | --- | --- |
| `A`（默认） | 学术蓝 | `0072B2` | Okabe & Ito Color Universal Design；Wong, Nature Methods 2011 |
| `B` | 深青蓝 | `283E4E` | v0.3 主题色系保留（深档） |
| `C` | 砖红 | `A63603` | ColorBrewer 暖调（红紫/橄榄组合） |

**换预设 = 整套换**：`--preset B` 一次替换全部 token，不接受只换点缀色的"半套配色"。
需要自定义品牌色时（模板跟随场景），用 `palette_utils.py --scale <基色>` 派生同色相色阶，
再用 `--contrast 前景 背景` 逐档核对比度；文字 token 必须 ≥4.5:1。

## 硬门槛（全部档位通用）

- 正文文字对比度 **≥4.5:1**（hair 的 HF 页眉页脚档豁免，且必须位于页眉/页脚几何区）。
- 非 token 色出现在文字上即报 `PAL.COLOR`；图表文字色同样受限（`PAL.CHARTCOLOR`）。
- 点缀色每页限额按档位（strict ≤2 / balanced ≤3，按形状计，`PAL.ACCENT_PAGE`）。
- 图表被点亮的标记 ≤1 处（`PAL.CHART_SERIES`）；"只点亮一根"必须建立在截断轴诚实标注、差异可见之上。
- 非中性色相 ≤3 组/页（`PAL.HUE`，WARNING）。
- 浅档只做填充、底色和分隔，不承载正文小字。

## 自检命令

```text
python scripts/palette_utils.py --check                # 自检 + 预设 A 对比度表
python scripts/palette_utils.py --check --preset C     # 预设 C 对比度表
python scripts/palette_utils.py --contrast 0072B2 FFFFFF
python scripts/palette_utils.py --scale 1F4E79         # 自定义基色派生色阶（模板跟随用）
```

## 常见错误

- 只换色相不看明度：色相差 180 度不代表对比度达标。
- 浅档当正文色，或在浅底上写浅字。
- 把 `chart_neutral`/`series` 当文字色用。
- 需要第二点缀色时自造颜色，而不是从预设 series 里取。
- 一页塞进四组以上色相，视觉上变成彩虹页。

# 配色系统

配色权威定义在本文件；脚本 `scripts/palette_utils.py` 是它的可执行实现，其他文档只引用，不重复阈值。

## 三类颜色

| 类别 | 作用 | 是否占配色额度 |
| --- | --- | --- |
| 中性色 | 黑、白、灰，底色、正文、分隔线的基础 | 否，不计入任何限制 |
| 主题色 | 主色系列，承担标题、正文重点、主图形 | 是 |
| 对比色 | 与主题色明确区分的暖色系列，只用于关键强调 | 是，面积最小 |
| 辅助色 | 低饱和次级系列，用于分区、次要系列、附属信息 | 是 |

**主题色是一个系列，不是一个颜色。** 指定"红色"时要给出深浅与明暗不同的若干档，而不是一个色值。

## 默认色阶

主题色 `#283E4E` 七档，从深到浅：

```
#142129  #1E303B  #283E4E  #4A6577  #8199A8  #B7C7D2  #E4EBF0
```

对比色（暖琥珀）四档：

```
#8C5A16  #B4771F  #C98B2E  #E0B15B
```

辅助色（灰青绿）四档：

```
#2F4E48  #4F7C74  #8DB0A8  #D6E5E1
```

换主题色时用 `palette_utils.generate_scale()` 按明度阶梯派生同系列色阶，保持"一个色相、多档明度"的结构。

## 三层结构

1. **语义角色**：正文、背景、标题、重点、辅助信息、图表系列。
2. **色阶用途**：深档用于标题、正文和描边；中档用于图形填充；浅档用于背景、分区与弱化。
3. **实际对比度校验**：按最终前景色与背景色计算，包括透明叠加后的实际颜色，而不是只看色板。

**色阶不等于可用色。** 相对白底对比度：`#8199A8` 2.98:1、`#B7C7D2` 1.73:1、`#E4EBF0` 1.20:1，`#B4771F` 3.75:1、`#C98B2E` 2.91:1、`#E0B15B` 1.98:1，`#8DB0A8` 2.36:1、`#D6E5E1` 1.30:1——这些只能做填充、底色和分隔，不能承载正文小字。

## 硬门槛

- 正文对比度 **≥ 4.5:1**；大字（WCAG 大文本口径：≥18pt 常规或 ≥14pt 加粗；本规范正文下限 16pt 已高于常规阈值）与图形边界 **≥ 3:1**。
- 单页色相组 **≤ 3 组**（黑白灰不计入，色相按 30 度分档）。
- 对比色形状填充面积 **≤ 10%**（提醒）、**≤ 20%**（上限）。
- 辅助色形状填充面积 **≤ 20%**（提醒）、**≤ 35%**（上限）。
- 面积口径统一为**形状填充与单元格填充面积占页面面积的比例**；照片、渐变和纹理背景不参与计算，改用不透明底板后人工复核。

超过面积上限报错或警告，具体分档见 `scripts/verify_ppt_style.py`：对比色超 10% 提醒、超 20% 报错；辅助色超 20% 提醒、超 35% 报错。

## 校验与自查

```text
python scripts/palette_utils.py --check          # 打印色阶与对比度表
python scripts/palette_utils.py --contrast 4A6577 FFFFFF
python scripts/palette_utils.py --scale 1F4E79   # 从自定义基色派生色阶
python scripts/check_ppt.py deck.pptx --accent 1F4E79 --contrast-color 8C5A16 --support 2F4E48
```

- 配色、对比度、字号由 `verify_ppt_style.py` 判定；`check_ppt.py` 负责汇总。
- 颜色继承自母版或主题、无法判定对比度的，报警告而不是放行。
- 文字颜色继承（未显式设置）在平衡档是警告，严格档是错误。

## 常见错误

- 把灰色当作"第四种颜色"来限制：中性色不计入额度。
- 只换色相不看明度：色相差 180 度不代表对比度达标。
- 浅档当正文色，或在浅底上写浅字。
- 对比色大面积铺底，把强调变成噪音。
- 一页塞进四组以上色相，视觉上变成彩虹页。
