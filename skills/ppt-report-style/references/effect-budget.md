# 效果预算与章节母题

本文件定义母题、单页效果预算和禁止项。

## 章节母题

- **每章一个视觉母题，章节之间切换。** 例如第一章用弧线语言，第二章用层叠面，第三章用圆形节点。
- 母题数量是**软建议**：默认 3 个，建议不超过 5 个，超过 5 个需要说明理由，**不设硬上限**。章节多于 5 个时允许超过，但要在大纲里写明每个母题对应的章节。
- 母题不是"每页必须出现同一个元素"，而是同一章内共享的图形语言：弧线、路径、节点可以同属一个母题。
- 母题按大纲元数据记录，字段建议：章节 / 母题名称 / 图形语言 / 使用强度 / 与内容关系的匹配理由。

## 单页效果预算

- 每页最多 **1 个主效果 + 1 个辅助效果**，都可以省略到 0。
- 主效果服务于本页的关系模型；辅助效果只做弱化或分区。
- 效果强度不得超过内容层级：不要让装饰比结论更醒目。

## 禁止项

- **不使用 SmartArt**。新建或重设计页面用普通文本、表格、形状或图表表达结构；源文件已有 SmartArt 时保持原状，需要改动先征得用户同意。
- 无意义渐变、阴影堆叠、发光、倒影。
- 为凑视觉而增加的装饰元素或图标。
- 一页堆叠多种形状形成"形状动物园"。
- 为通过检查而机械添加的效果。

## 例外机制

合理的连续布局、模板跟随和内容驱动设计可以声明例外，而不是被机械判错：

- 在页面备注里写 `[例外:骨架重复]` 加一句理由，检查脚本会跳过该页的骨架重复判定。
- 结构性例外（如沿用原模板保留 SmartArt）用 `--allow-smartart`。
- 需要长期保留的例外写进例外记录 JSON，用 `--exceptions exceptions.json` 传入，格式：

```json
{"exceptions": [{"rule": "LAY.REPEAT", "slides": [3, 4, 5], "reason": "逐步揭示同一张图"}]}
```

例外不会降级安全性、版权和可读性相关规则：对比度、字号、缺失图片和禁用对象仍然报错。
