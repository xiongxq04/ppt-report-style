# 汇报 PPT 规范

## 硬性限制
- 字体分两槽：**中文只用 宋体 / 楷体 / 黑体**（写进 `a:ea`），**西文只用 Arial / Times New Roman**（写进 `a:latin`）。字号只走下面"字阶"的 6 档，**最小 16pt**。
- 文字只有三色：黑 `000000`、白 `FFFFFF`、主题色 `#283E4E`。灰色不得用于文字；底纹可用 `F1F5F8`，边框 `B7C1C8`。
- 内容变多时**减字，不缩字号**。
- 不在正文块里加"西方的问题""中国的做法""关键指标"这类段落小标题，内容直接写。
- 指标名与数值写在**同一句**里，不做"上面指标名、下面数值"的两层结构。
- 标题用命题式表述，不写口水话。

## 字阶与字体分工（内容 → 字体 / 字号对照表）
只有这 **6 档**：`16 / 18 / 20 / 30 / 36 / 44`。落在档外即视为层级失控，`verify_ppt_style.py` 会报"字号不在字阶内"。

| 层级 | 用在什么内容 | 中文（a:ea） | 西文（a:latin） | 字号 | 行距 | 颜色 |
| --- | --- | --- | --- | --- | --- | --- |
| 封面主标题 | 首页标题，≤12 字 | 黑体 | Arial | 44 | 1.1 | 主题色 |
| 章节 / 大标题 | 章节页、图形区大标题 | 黑体 | Arial | 36 | 1.1 | 主题色 |
| 页面标题 | 每页命题句，≤32 字 | 黑体 | Arial | 30 | 1.15 | 主题色 |
| 副标题 | 口径、范围、时间、方法说明 | 宋体 | Times New Roman | 20 | 1.2 | 黑 |
| 导语 / 引文 | 左栏首段、引用原话 | 楷体 | Times New Roman | 20 | 1.3 | 黑 |
| 正文 | 实证条、判断块、结论条 | 宋体；判断与结论换黑体 | 随中文配对 | 18 | 1.2–1.4 | 黑；判断与结论主题色 |
| 表格 | 表头黑体白字，正文宋体 | 黑体 / 宋体 | Arial / Times New Roman | 16 | 1.0–1.1 | 白 / 黑 |
| 图注 · 页眉 · 页码 · 图形内文字 | 辅助信息 | 宋体 / 黑体 | Arial | 16 | 1.0–1.1 | 主题色 / 黑 / 白 |
| 大数字块 | 圆、六边形内的统计数值 | — | Arial | 36–44 | 1.0 | 主题色 |

- **一页最多 5 档**（六档里取，落地一页通常 3–5 档）。同一层级全篇同档，不许这页 18、下页 19。
- 标题与正文的比例：页面标题 30 ÷ 正文 18 ≈ 1.7，封面 44 ÷ 18 ≈ 2.4；网络常见区间 1.8–2.2，命题式长标题取低值以免换行。
- **16pt 是硬下限**，比网络常见的 14pt 更严——投影后排可读优先，放不下就减字。
- 字重：黑体**不再叠加粗体**（合成粗会糊边），宋体、楷体不加粗；强调一律"换黑体 + 主题色"。
- 楷体每页最多一处（导语或引文），不进表格、不进图形。
- 数字随文走：正文里的数字用该行配对的西文字体（宋体语境 → Times New Roman）；独立大数字块一律 Arial。

## 中英混排（英文、数字、缩写）
- **两槽都要显式写**：python-pptx 的 `run.font.name` 只写 `a:latin`（西文槽），中文字形取 `a:ea`。只设 `font.name="宋体"` 会让英文用宋体的西文字形渲染——字距松、字形丑，而且旧版校验查不出来。
- 配对建议（非硬性，但同一页内保持一致）：黑体 → Arial；宋体 / 楷体 → Times New Roman。不要一行 Arial、一行新罗马混着排。
- 中文与英文、数字之间加一个半角空格：`11 个项目`、`前 20 秒`；纯英文短语内部不加。
- 英文字母与数字一律半角，禁止 `ＢＰＭ`、`２０２４`；全角只留给中文标点。
- 括号按外层语言选：中文句子里用 `（app.py）`，不写成 `(app.py）`。
- 缩写首次出现给中文全称：`MIR（音乐信息检索）`；表格里可只留缩写，口径写进备注。
- **长英文 token 是溢出主因**：`conversation_log.csv` 这类无空格串不能逐字断行，只能整体换行。放进宽栏、手动用空格或 `·` 断开、或改写成中文；不要指望缩字号解决。
- 不为代码或文件名引入第三种西文字体；需要等宽效果就改写成中文描述，或放截图。

## 先大纲，后页面（硬门槛）
- **生成任何页面之前，先写一版一页纸大纲**并交用户确认（或至少自查一遍）再动手。
- 大纲用表格，每页一行：**页码 / 命题式标题 / 核心判断（一句话）/ 上片的实证 / 图形形式与几何记忆点 / 讲稿要点与时长**；表外再列**待确认事项**（听众、时长、是否加代码页、是否加推导页）。
- 大纲里每个数字都要能追溯到材料或实算结果，标注口径与出处。
- **内容结构一旦要改，先改大纲再改页面**，不要在成稿页面上改结构——那是返工最多的一种改法。
- 大纲未确认，不进入生成阶段。

## 表格与方块的取舍
- **强数据类型、强主题的内容用表格**（对齐的行列结构，适合指标对比、口径对照）。
- 叙事、机制、并列要点用**方块/方格**，块内直接写内容。
- 不要把两种结构混在同一页里各占一半。

## 页面骨架
- 左边距 0.55in，正文宽约 12.96in。纵向网格（14.06×7.91in 页面，已实测过审）：页眉 `T=0.24 H=0.34`（16pt）→ 标题 `T=0.56 H=0.66`（30pt 主题色）→ 副标 `T=1.26 H=0.46`（20pt）→ `#283E4E` 细线 `T=1.76` → 正文区 `1.86–6.67` → 结论条 `T=6.80 H=0.62`。
- 框高按字号反推：单行需要 `字号 × 1.2 × 1.18`，20pt 至少 0.46in、18pt 至少 0.42in、16pt 至少 0.38in；照抄旧稿的 0.28–0.36in 小框会被判溢出。
- 默认**左文右图双栏**（左约 7.1in、右约 5.7in、间距 0.2in）：左栏 = 楷体导语块（20pt）→ 3 条实证（18pt，每条左侧 0.045in 主题色竖条）→ 黑体判断块（18pt 主题色）；右栏 = 配图 + 图表 + 几何记忆点。
- 底部固定一条全宽结论条：0.045in 竖条 + 18pt 黑体一句判断。
- 强调块统一为浅底 `F1F5F8` + 左侧主题色竖条，不做全包边框。

## 密度与几何
- 实证条 1–2 行，判断块 2–3 行；行距按字阶走（标题 1.1–1.2、正文 1.2–1.4、表格 1.0–1.1），块间约 0.1in 均匀缝隙，页面下缘留白不填死。
- **每页一个几何记忆点**，同批页面各不相同（圆形、三角形、环形图、圆点线路、六边形等），但页眉、栏宽、字号保持一致——统一中求变化。
- 图表坐标轴留余量，数值标签不贴边、不被裁；几何形状与文字块中线对齐，不压字。
- 图片按框**裁切填满**，不拉伸变形，边缘与文字块对齐。

## 内容与备注
- 数据只来自用户提供的材料（Word/课件/来源文件），不编造、不自造词；旧数据按材料里的最新口径更新。
- 数据来源、口径、备答写进**备注**，不上片。
- 每页备注写约 1 分钟逐字稿，可含口径备答。

完整分阶段流程（接单 → 材料 → 版式 → 生成 → 三道自检 → 交付）见 `references/workflow.md`；出现返工触发条件时按该文件处理。

## 字符与记号（避免豆腐块与歧义）
- 中文字符一律限制在 **GBK 可编码范围**：宋体/黑体/楷体都能覆盖 GBK，超出就可能出现豆腐块。交付前用 `scripts/audit_ppt.py` 的"字形缺失"项兜底。
- **数学上下标写成 ASCII**：`V^T`、`σ1`、`σi`、`1e-8`、`O(nk^2)`；不要用 `ᵀ`、`₁`、`²`、`⁻⁸` 这类字符（宋体很可能没有）。
- 生成脚本里的**强调标记不要用 `[[ ]]`**（会与矩阵记号 `[[1,2],[3,4]]` 冲突），用 `{{ }}`。
- 公式块优先用"大字 + 短句"表达，不要用长行 ASCII 公式。

## 图表与几何细节
- 数值标签设为外侧端点（OUTSIDE_END）时，**给坐标轴留余量**：把轴上限设为最大值的约 1.2 倍，否则标签会贴边或被裁。
- 类别多时（≥4 类）柱宽要留间隔，避免柱子挤成一条线；条形图同理。
- 散点图把 `scatterStyle` 设为 `marker`，否则默认会带连线。
- 形状几何：圆/三角/六边形等纯色块放满标题栏或作为统计块；白底描边图形（圆→椭圆示意）必须显式描边，否则在白底上"消失"。
- 同一页里所有形状的坐标以 **0.05in 为网格对齐**，视觉才成体系。

## 交付前机器审查（先跑脚本，再看预览）
```
python scripts/audit_ppt.py 你的.pptx      # 越界/溢出/西文不可断行/重叠/字体槽/字形/备注/表格
python scripts/verify_ppt_style.py 你的.pptx  # 字号/配色/中文(ea)与西文(latin)双白名单
python scripts/preview_ppt.py 你的.pptx out.html --slide 0
```
- 宽度估算：中文按 1.0 em，西文按字符分类（`i l` 0.30、数字 0.58、大写 0.72、`M W` 0.90），并**按"只在空格与中文处断行"模拟真实换行**；宁可估宽，不要漏报。**宁可略留余量**，框高留 10% 保险。
- 表格单元格按栏宽单独算换行：单元格被撑高会压到下方图形，这类问题只有预览图能看出来——审完脚本必须再看一眼预览。
- 字体槽检查会分别报：`a:ea` 缺失或不在中文白名单、`a:latin` 填了中文字体（英文将用中文字形渲染）、`a:latin` 不在 Arial/新罗马之内。
- 跑历史文件时可加 `--allow-cjk-latin` 放行西文槽的中文字体；新稿不要加。
- "文本重叠"只比较**有文字**的形状之间的交集，占小块面积 >18% 才算问题。

## 依赖（缺失时安装）
- 必需：`python-pptx`（生成与校验）。安装：`python3 -m pip install python-pptx`，有 `uv` 时优先 `uv pip install python-pptx`。
- 可选：Playwright + Chrome（把 `scripts/preview_ppt.py` 产出的 HTML 截成图片）；缺浏览器时直接把 HTML 交给用户打开。
- 字体：宋体/楷体/黑体是中文 Office 常见字体；系统缺失时**先问用户**是否接受替代字体，不要静默替换。西文 Arial 与 Times New Roman 在 Windows / Office 默认可用。生成时两槽都要显式写，可直接抄 `scripts/build_example.py` 里的 `font(run, size, color, face, latin=None)`。
## 可配置项（默认值即个人规范）
| 项 | 默认 | 改法 |
| --- | --- | --- |
| 主题色 | `#283E4E` | 生成脚本换常量；校验脚本用 `--accent` |
| 最小字号 | 16pt | 校验脚本用 `--min-size` |
| 字阶（允许字号档） | 16,18,20,30,36,44 | 校验脚本用 `--sizes "16,18,20,28"`；每页档数用 `--max-steps` |
| 中文字体白名单（a:ea） | 宋体,楷体,黑体 | 校验脚本用 `--fonts "宋体,黑体"`；系统缺字体时先问用户 |
| 西文字体白名单（a:latin） | Arial,Times New Roman | 校验脚本用 `--latin-fonts "Arial"` 收紧；不要往这里加中文字体 |
| 额外允许色 | 无 | 校验脚本用 `--allow-colors` |
| 备注最少字数 | 150 字/页 | 审查脚本用 `--notes-min` |

## 随附资源
- `assets/example-slide.pptx`：两页中性示例（方块+几何记忆点页 / 表格页），含中英混排写法，全部为占位数据，可直接看版式；用 `scripts/build_example.py` 重新生成。
- `scripts/verify_ppt_style.py`：字号、配色、中文字体（`a:ea`）与西文字体（`a:latin`）双白名单校验。
- `scripts/audit_ppt.py`：越界、文本溢出、西文不可断行、表格单元格撑高、元素重叠、字体槽、字形缺失、备注缺失等结构性审查（交付前必跑）。
- `scripts/preview_ppt.py`：pptx → HTML 预览（按 latin + ea 双槽拼字体栈，图表近似渲染）。
- `references/workflow.md`：完整分阶段流程与返工触发条件。
- `references/eval-queries.json`：20 条触发测试用例，用于改动 description 后回归触发率。
## 交付与安全
- 需要改单页时**单独输出一个 pptx**，不覆盖用户正在编辑的源文件。
- **绝不调用 PowerPoint COM 或操作用户打开的窗口**，只做文件读写。
- 改完先出预览图给用户确认，再提交；用 `scripts/verify_ppt_style.py` 校验字号与三色，用 `scripts/preview_ppt.py` 生成 HTML 预览（需要截图时用 Playwright 对 `.slide` 元素截图）。
- 纳入版本管理时只提交本次新增/修改的交付文件，不提交用户自己在改的文件；中间产物放临时目录并忽略。
